## `readability-guide.md` 구성

1. **목적/성격** — 정본과의 관계, "진단 렌즈이지 강제 규칙 아님", 정확성 우선, 정본·AGENTS 링크.
2. **읽힘 진단 렌즈** — #92의 렌즈 세트(독자 변화 중심 / 훅과 동기 / 중심 질문 / 이해 순서 / 문단의 추진력 / 완급 / through-line / 추상과 구체의 왕복 / 결론의 변화 / 작성자의 관점 / 직관-엄밀 / 코드 설명 / 선택과 삭제). 정본과 겹치는 항목(`[정본]` 표시: 중심 질문·이해 순서·직관-엄밀·코드 설명·선택과 삭제)은 **재규정하지 않고 정본 섹션을 링크**만 한다. 렌즈 관계 문단(독자 변화=목적지 … 결론이 회수)을 둔다.
3. **정확성 우선 (가드레일)** — 몰입이 조건 생략·직관의 증명화·재현 안 되는 단정을 정당화하지 않는다. 원문 보존·provenance 우선.
4. **적용과 검토** — 작성 단계 질문 / 리뷰 질문(작성자 자가 적용용). **review-post 게이트가 아님**을 명시. 세부 확장은 필요 시 별도 정리.

## 원문 보존 정합

- "이해 순서", "선택과 삭제"의 재배치·삭제 제안은 `AGENTS.md`의 원문 보존 규칙 범위 안에서만 한다. 삭제 승인이 없으면 제거하지 않고 검토 대상으로 표시한다(#92에서 확정한 안전장치를 그대로 반영).
