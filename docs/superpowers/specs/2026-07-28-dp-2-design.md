## 목표

DP①이 "이미 주어진 점화식(피보나치)을 어떻게 빠르게 계산하는가"였다면, ②는
그 앞 단계인 **"점화식을 어떻게 세우는가"**로 도약한다. 소재는 노션의 *일할 날짜
고르기*: 날마다 일급이 다르고 **연속된 날에는 일할 수 없을 때** 총 일급을
최대화하는 문제(경로 위 최대 가중 독립집합, House Robber류). 핵심 교훈은
**"최적해가 마지막 날을 포함하는가?"라는 결정 하나에서 점화식이 유도된다**는 것이다.

## 스코프 결정 (브레인스토밍 확정)

- **소재는 일할 날짜 고르기 하나만.** 노션 DP2에 함께 있는 *행렬 곱셈 순서(matrix
  chain / 구간 DP)*는 이 글에 넣지 않고 **DP③으로 미룬다**. (난이도·분량, 기존
  matrix-multiplication 글과 이름 충돌 회피)
- **뼈대는 노션 원본 그대로**: 문제 정의 → Naive($2^n$) → DP(포함 A / 제외 B
  논증) → 2행 테이블 코드 → 구체 예시로 표 채우기.
- 노션 저자 노트를 그대로 반영한다:
  - *"이거 좀 잘 풀어서 써주라. 이미지 첨부하면 더 좋고"* → A/B(포함/제외) 논증을
    자세히 풀어 쓰고 case-split SVG를 붙인다.
  - *"svg로 실제 예시로 어떻게 하는지 보여줘"* → table-fill SVG로 구체 예시를 채운다.
  - *"내용을 모르면 왜 저렇게 하는지 알 수 없다…"* → 2행 코드에 설명을 붙인다.
- **Naive $2^n$는 한 줄만.** 지수 재귀→중복 부분 문제 이야기는 DP①에서 충분히
  다뤘으므로 되풀이하지 않는다.
- **traceback(선택 복원)·O(1) 공간 최적화는 노션에 없는 확장분**이다. 본문 마지막에
  **"더 나가면" 한 단락**으로, 노션 밖 확장임을 명시하고 짧게만 언급한다. 별도
  '추가 설명' 페이지는 만들지 않는다.
- difficulty는 **중급**(①은 초급 → 점화식 *유도*가 들어가며 한 단계 올라감).

## 예시 배열 (확인 필요 항목)

- 본문·SVG 공용 예시: **`a = [3, 5, 6, 10]`** (1-indexed), 정답 **15 = 2·4일 선택**.
- 이 값은 노션 이미지가 판독 불가여서 **본문 텍스트 힌트**(첫날 3·다음날 5,
  "마지막에서 두번째 날(6)", "S(n-2) + 10")에서 **복원**한 것이다. 검산:
  - $S_1=3,\ S_2=\max(5,3)=5,\ S_3=\max(5,3{+}6)=9,\ S_4=\max(9,5{+}10)=15$.
  - 2행 코드로도 동일: `r[4][1]=r[3][0]+10=5+10=15`, `max(r[4][0],r[4][1])=15`.
- 노션의 실제 예시 숫자가 다르면 그 값으로 교체한다(스펙 리뷰 시 확인).

## 본문 구성

1. **되짚어보기 & 전환** (도입 blockquote)
   - ①은 피보나치로 재귀→메모이제이션→상향식을 봤고, **점화식은 이미 주어져
     있었다**.
   - ②는 점화식이 없는 문제에서 **점화식을 직접 세운다**. 소재: 일할 날짜 고르기.
2. **목차 callout** (`이 포스트에서 다루는 내용`).
3. **문제** (`## 일할 날짜 고르기`)
   - 일급 배열, 연속된 날 근무 불가, 총 일급 최대화.
   - 예시 `[3,5,6,10]` 제시. 완전탐색은 날마다 일함/안 함 → $2^n$ 언저리(한 줄).
4. **결정 하나로 쪼개기** (`## 마지막 날을 포함하는가`) — 글의 심장
   - $S(n)$ = 앞 $n$일에서의 최대 일급. 최적해가 **마지막 날을 포함하는지**로 이분.
   - **포함(A)**: 마지막 날 일급 $a_n$을 얻지만 $n{-}1$일은 **강제로 못 일함** →
     남은 최선은 $S(n{-}2)$ → $A = S(n{-}2)+a_n$.
   - **제외(B)**: 마지막 날을 안 하면 $n{-}1$일 제약이 사라져 → $B = S(n{-}1)$.
   - 두 경우가 **겹침 없이 전부**(MECE)이므로
     $S(n)=\max\big(S(n{-}1),\,S(n{-}2)+a_n\big)$.
   - `thm`/`proof` 환경으로 최적 부분구조("$S(n{-}2)$, $S(n{-}1)$이 각자 최적이어야
     $S(n)$도 최적")를 간단히 논증.
   - **case-split SVG** 삽입.
   - 기저: $S(0)=0,\ S(1)=a_1$. (콜아웃으로 경계 조건 강조)
5. **코드와 표 채우기** (`## 상향식으로 채우기`)
   - 노션의 **2행 테이블** C++ 의사코드: `r[i][0]`(i일에 일 안 함 중 최선),
     `r[i][1]`(i일에 일 함 중 최선). 점화:
     `r[i][0]=max(r[i-1][0],r[i-1][1])`, `r[i][1]=r[i-1][0]+a[i]`.
   - 코드 각 줄이 왜 그런지 설명(저자 노트 반영). 1D $S(\cdot)$ 형과의 대응도 한 줄.
   - **table-fill SVG**로 `[3,5,6,10]`을 왼→오 채우고 끝에 15·선택일(2·4) 강조.
   - 복잡도: 칸마다 상수 작업 → **$O(n)$ 시간, $O(n)$ 공간**.
6. **더 나가면** (`## 더 나가면`) — *노션 밖 확장, 명시*
   - 채운 표를 뒤에서 되짚으면 **어느 날을 골랐는지**까지 복원할 수 있다(값과 구성
     둘 다). 한두 문장.
   - 점화식이 **직전 두 값만** 참조하므로 표 대신 변수 두 개로 **$O(1)$ 공간**.
     단, 선택 복원엔 표가 필요하다는 트레이드오프 한 줄.
   - 이 단락은 "강의 노트 범위를 넘어선 참고"임을 분명히 한다.
7. **마치며**
   - ①=점화식 계산, ②=점화식 유도("마지막 원소를 포함하나?"라는 결정)로 요약.
   - DP③ 예고: 같은 결정 사고를 **구간**으로 확장 → 행렬 곱셈 순서(구간 DP).
   - 하단 시리즈 링크: `[동적 계획법 ① →](/blog/dp-1)` 등.

## SVG 계획 (2개)

- `public/images/dp-2/case-split.svg`
  - 최적해 $S(n)$에서 마지막 날 포함/제외 두 갈래.
  - 포함 → $a_n$ 획득 + $n{-}1$일 잠금(X 표시) + $S(n{-}2)$.
  - 제외 → $S(n{-}1)$.
  - 아래 `S(n)=max(S(n-1), S(n-2)+aₙ)` 표기.
- `public/images/dp-2/table-fill.svg`
  - 상단: 일자·일급 `[3,5,6,10]`.
  - 2행 표(일 안 함 / 일 함)를 왼→오로 채운 값 표시:
    안 함행 `0·3·5·9`, 함행 `3·5·9·15`(1-indexed 기준 재확인).
  - 각 칸이 어느 이전 칸에서 왔는지 화살표(선택된 전이 강조).
  - 최종 `max=15`, 선택일 `2·4` 하이라이트.
  - 뷰박스·팔레트·폰트는 기존 알고리즘 글 SVG와 통일(#0f1117 배경 등).
