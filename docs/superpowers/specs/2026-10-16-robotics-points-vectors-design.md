- 날짜: 2026-10-16
- 브랜치: `feat/robotics-points-vectors` (`origin/main`에서 분리한 worktree)
- 독자: 사용자가 확인한 «고교 수학을 잊은 독자».
- 목적: 프로젝트의 기구학을 삼각함수·벡터부터 그림으로 공부하고 블로그로 정리한다.
- 승인 범위: 인계된 대화의 기초 1 본문, SVG, 실험 하나, 최소 실험 기반, robotics 카테고리를 한 PR에 담는다. 2026-10-16 이어서 작업 요청에 따라 진행한다.

## 질문과 결론

점의 위치와 두 점 사이의 변위는 무엇이 다른가? 원점을 옮기되 축 방향과 길이 단위를 유지하면 점의 좌표는 바뀌지만 두 점 사이의 변위 성분과 거리는 같다. 좌표계 회전까지 성분이 불변이라고 확대하지 않는다.

## 본문 순서

1. 로봇 손끝 A에서 목표 B로 가는 작은 문제.
2. 직교좌표, 원점, 축, 음수 좌표, 길이 단위.
3. 끝점 좌표에서 시작점 좌표를 빼서 변위 성분을 얻는다.
4. 피타고라스 정리로 변위의 길이를 구한다. 이동 경로의 길이와 구분한다.
5. 원점만 옮긴 계산과 일반식으로 불변성을 보인다.
6. 점·원점을 직접 옮기는 실험. 같은 점, 반대 방향도 확인한다.
7. 위치벡터와 자유벡터의 차이를 정리하고 다음 삼각함수 글의 질문을 남긴다.

수학은 2차원 유클리드 평면, 서로 수직인 축, 두 축에 같은 단위를 전제로 한다. 본편에 원점 변경의 조건과 영벡터의 예외를 남긴다. 회전행렬·내적·외적·추상 벡터공간 공리는 후속 범위다.

## 근거와 provenance

- 원문: 사용자 제공 `공수-선대.pdf` 2·5쪽(기하적 벡터, 좌표 성분의 연산), 20–24쪽(일차결합). 기존 대화에서 실제 파일을 pypdf로 읽었다.
- 원문: 기구학 PPT 4·8·9쪽(점과 방향의 변환, 원점 변경), 레일 HTML 도입(원점·축·local/world). 이 글은 회전을 도입하지 않는다.
- 승인된 추가: 사용자와 인계 대화가 정한 점/벡터 입문 설명과 실험. A=(1,1), B=(4,5), 새 원점=(1,2)의 무차원 학습 예시는 이 목적에 맞춘 추가다.
- 공개 대조: OpenStax, Algebra and Trigonometry 2e §10.8 Vectors, https://openstax.org/books/algebra-and-trigonometry-2e/pages/10-8-vectors (2026-10-16 확인). 좌표·변위·크기의 정의를 대조한다.
- 미분방정식 PDF는 시리즈 보충편의 근거이며 이 편에는 쓰지 않는다. 삼각함수 이전에 미분을 요구하지 않는다.
- 비공개 원천의 경로나 존재를 게시 본문에 드러내지 않는다. 공개 문헌만 본문에 연결한다.

## 실험 기반 결정

A안(빌드 시 인라인 + 실험별 JS)을 채택한다. 실제 단계 플러그인은 raw HTML wrapper가 아니라 파일명으로 찾으므로, 이 관례대로 `-lab.svg`를 Markdown 이미지로 넣는다. SVG 루트의 `data-lab="point-vector"`와 닫힌 모듈 목록이 실험을 결정한다. 본문에 스크립트나 수백 줄 마크업을 넣지 않는다.

- 별도 rehype 플러그인이 figure 안의 해당 이미지에만 적용된다. 기존 단계 재생기의 누적 규칙은 변경하지 않는다.
- 기존 ID 접두어 함수를 재사용하고, 같은 파일을 두 번 써도 다른 인스턴스 접두어를 부여한다.
- 원본 img를 정적 상태로 보존하고, 같은 SVG로 만든 인라인 복사본은 초기화가 성공한 후에만 보인다. JS 차단·모듈 실패·인쇄에는 원본 이미지가 보인다.
- public/images 내부의 규약에 맞는 경로만 읽는다. 미등록 실험·읽기 실패·지원 밖 SVG는 정적 이미지로 남긴다.
- 초기 로더는 작은 등록부이며 실험 모듈은 실험이 있는 페이지에서만 동적으로 가져온다.
- 새 패키지는 추가하지 않는다. 기존 Node 내장 테스트와 CI 설치 없는 테스트 계약을 유지한다.
- iframe 자체가 JS 없이 빈 화면이 되는 것은 아니다. 정적 HTML도 표시할 수 있다. A안은 이 블로그의 기존 저작·검사 구조를 활용하기 위해 택한다.

## 실험 상호작용

A, B, 원점 O를 끌거나, 조작 대상을 선택한 뒤 두 native range 입력으로 옮긴다. 점의 입력은 현재 원점 기준 좌표, 원점의 입력은 처음 원점 기준 이동량으로 명시한다. 축 방향과 단위는 고정한다. 초기 A=(1,1), B=(4,5), O=(0,0), 변위=(3,4), 거리=5다. 재설정으로 복원한다.

점과 원점은 모양과 문자로도 구별한다. A=B이면 영벡터와 거리 0을 표시하고 방향 화살표를 숨긴다. 모바일에서 드래그하지 않아도 입력으로 모든 조작을 할 수 있다. 자동 재생·불필요한 움직임은 없다.

## 시각과 범위

팔레트는 이미 승인된 `docs/design/DIAGRAM_PALETTE.md`를 따른다. 어두운 도판은 사이트의 모티프이며 다크 모드 토글이 아니다. SVG의 팔레트 매핑을 실험까지 확장하되 기존 값은 바꾸지 않는다.

카테고리 두 스키마와 categories 데이터에 robotics를 더한다. 시리즈 순번·전용 이전/다음·안내 글은 다음 편의 범위다. 기초 4=원점 중심 평면 회전, A1=이동과 local/world, A3=공간 회전의 경계를 유지한다.

## 검증과 리뷰 인계

실험 모델: 원점 이동 불변성, 순서 반전, 영벡터, 범위·유한 입력. 플러그인: 미등록·누락·경로 이탈·같은 SVG 중복·ID 참조와 정적 fallback. 팔레트 검사에 새 실험 SVG를 포함한다.

브라우저: 데스크톱·좁은 폭에서 점/원점 조작, 키보드, 재설정, 그림 중복·라벨 겹침, JS 차단 상태, 인쇄 스타일, 기존 단계 재생기를 확인한다. 실행한 것과 미확인인 것은 리뷰 인계에서 구별한다.

작성 단계에서 `npm run test:js`, `npm run build`, 결정적 포스트 검사와 저장소 gate를 실행하고 그림·본문·모델의 예시를 대조한다. 계산·논증과 시각 확인은 리뷰 인계에 근거를 남긴다. `docs/writing-rules.md`의 작성자·리뷰어 책임 구분에 따라 독립 리뷰어의 L1–L7 판정과 strict finalize는 PR의 완료 조건으로 남긴다. 작성자의 자체 검증을 독립 리뷰로 기록하지 않으며, PR은 draft로 연다.
