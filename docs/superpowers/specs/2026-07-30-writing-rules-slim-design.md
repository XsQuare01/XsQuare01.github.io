## 제거

### 모호(판단 렌즈)
1. **2단계 `##### 논증과 문단`** (5 bullets) — "주장부터 경로"·"새 독자 위치"는 2단계 공통 필수와 중복, "문단마다 한 가지 일"·"뜻을 먼저 확정"은 소프트 판단, "추상어→관찰 가능"은 사례 1이 이미 시연. 전체 제거.
2. **3단계 `#### 초안과 퇴고 원칙`** (3 bullets) — 3단계 공통 필수(주장·근거 끝까지 / 내용·구조·문장 분리)와 중복. 전체 제거.
3. **5단계 `#### 문장과 독자의 시간`** (3 bullets, Didion·Vonnegut) — 몰입/읽힘 성격의 판단 렌즈. 제거. 재료는 이미 #92에 있음(별도 이관 안 함).

### 중복
4. **`## 완료 기준 (편당)`** — 11개 bullet 중 단계 체크리스트를 재서술·소프트 판단인 것을 제거하고, 고유한 완료 신호(provenance·구조 예외 인계, 자체 인증 금지, 의미·수식·코드 불변, `npm run build` 통과)만 남긴다.
