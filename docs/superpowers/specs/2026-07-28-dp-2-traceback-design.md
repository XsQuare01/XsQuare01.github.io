## 목표

dp-2의 DP는 최댓값 **15**만 돌려준다. 정작 "**어느 날**에 일해야 하는가"라는 계획은 아직 없다. 채운 표에는 그 답이 이미 들어 있고, **표를 거꾸로 읽으면** 최적해의 구성(선택한 날짜)을 복원할 수 있다. 이 페이지는 "DP는 최적'값'과 최적'해의 구성'을 따로 다룬다"는 일반 패턴을 일할 날짜 고르기로 보인다.

## 스코프 결정 (브레인스토밍 확정)

- 참고 페이지 = **선택 복원(traceback)만.** O(1) 공간 이야기는 dp-2 "더 나가면"에 **그대로 유지**한다.
- dp-2 "더 나가면"의 **복원 문단**은 이 페이지로 가는 **한 줄 링크**로 교체하고, **O(1) 문단은 남긴다.**
- 같은 브랜치 `content/dp-2`에서 dp-2와 함께 머지/PR. 포워드 링크가 한 번에 유효.
- difficulty **고급** (기존 '추가 설명' 페이지 관례와 동일 톤).
- 예시는 dp-2와 **같은 `[3,5,6,10]`**, 복원 결과 **{2일, 4일}**, 합 15.

## 본문 구성

1. **도입 blockquote** — dp-2의 답은 최댓값 15뿐. "어느 날 일하나"는 아직 없다. 표에 답이 있다. `[동적 계획법 ②](/blog/dp-2)` 링크. 강의 노트 밖 확장임을 한 줄로.
2. **목차 callout** (`이 포스트에서 다루는 내용`): 값 vs 구성 / 표를 거꾸로 읽기 / 예시 되짚기 / 역추적 의사코드 / O(1)과의 트레이드오프.
3. **값과 구성은 다르다** — DP는 최적'값'을 주지만 최적'해의 구성'(어느 원소를 골랐나)은 별도 복원이 필요하다. 대부분의 DP에 공통.
4. **표를 거꾸로 읽기** — 채운 2행 표를 마지막 칸부터 역추적:
   - 시작: `max(r[n][0], r[n][1])` 중 큰 쪽.
   - `r[i][1]`(i일 근무)에서 왔으면 → i일을 선택에 넣고 `r[i-1][0]`로(i−1 강제 제외) → i−2로.
   - `r[i][0]`(i일 쉼)에서 왔으면 → i일 미선택 → i−1로(그 칸의 큰 쪽으로).
5. **예시 `[3,5,6,10]` 되짚기** — r[4]: max(9,15)=15는 `r[4][1]`(4일 근무) → 4일 선택, `r[3][0]=5`로. r[3][0]=max(r[2][0],r[2][1])=r[2][1]=5(2일 근무) → 2일 선택, `r[1][0]=0`로. 결과 **{2일, 4일}**, 합 5+10=15. **traceback.svg** 삽입.
6. **역추적 의사코드** (C++, backward pass): 채운 `r`을 받아 선택 날짜 목록을 되짚어 만든다.
7. **미묘한 점 callout** — 동점(tie)일 때는 어느 쪽을 택해도 최적해 하나가 나온다(복원 결과가 여러 개일 수 있음). O(1) 공간으로 줄이면 표가 사라져 이 복원은 불가능하다 → dp-2 "더 나가면"과 상호 참조.
8. **마치며** — "값 + 구성"은 DP 전반의 패턴. `[동적 계획법 ② →](/blog/dp-2)` 링크.
