## 목표와 동기

dp-2는 *"마지막 원소를 포함하는가"* 라는 결정 하나에서 점화식 $S(n)=\max(S(n-1),\,S(n-2)+a_n)$ 을 세웠다. dp-3은 그 **결정 기반 사고를 구간으로 확장**한다: *"이 구간의 마지막 곱셈(= 최상위 괄호)을 어디서 하는가"*. dp-2 마치며가 이미 "이 구간을 어디서 나눌 것인가 … 행렬 곱셈의 곱셈 순서(구간 DP)가 다음 편의 주제"라고 예고해 둔 편이다.

이 글은 **곱셈 결과가 아니라 곱셈 순서**를 다룬다. 기존 `matrix-multiplication.md`(Strassen — 두 행렬을 빠르게 곱하는 법)와는 주제·슬러그가 분리된다.

## 표기 규약 (원문 정합성 · 검증)

- **표준·정본 규약**: 행렬 $M_i$ 는 $d_{i-1} \times d_i$ 크기. 사슬 차원은 $d_0, d_1, \dots, d_n$.
- $M_i \times \cdots \times M_j$ 의 최소 비용을 $M[i,j]$ 라 한다.
- 구간 $[i,j]$ 를 $k$ 에서 자를 때(마지막 곱을 $(M_i\cdots M_k)(M_{k+1}\cdots M_j)$ 로) 비용:
  $$M[i,j] = \min_{i \le k < j}\big(M[i,k] + M[k+1,j] + d_{i-1}\,d_k\,d_j\big)$$
- 기저: $M[i,i] = 0$ (한 행렬은 곱이 필요 없다).
- **예시 검증**: $(3\times2)(2\times4)(4\times2)$ 는 $d = [3,2,4,2]$.
  - $k=2$ 로 자르면(=`((·)(·))(·)`): $M[1,2] + 0 + d_0 d_2 d_3 = 24 + 0 + 3\cdot4\cdot2 = 48$
  - $k=1$ 로 자르면(=`(·)((·)(·))`): $0 + M[2,3] + d_0 d_1 d_3 = 0 + 16 + 3\cdot2\cdot2 = 28$
  - $\min = 28$. 노션 예시와 일치.
- 노션 DP2의 Matrix multiplication 절은 rough draft(indexing이 $d_i d_{k+1} d_{j+1}$ 로 다름)이고, DP3가 위 정제된 형태다. 두 페이지는 같은 주제이므로 함께 원문으로 삼되, 정본 규약으로 통일한다.

## 본문 구성

1. **오프닝 blockquote** — dp-2 링크, "원소 하나를 포함하는가 → 구간을 어디서 자르는가" 로 연결.
2. **callout "이 포스트에서 다루는 내용"** — 4~5개 불릿.
3. **## 곱셈 순서가 비용을 바꾼다** — 행렬 곱 $(p\times q)(q\times r)$ 비용 $= p\cdot q\cdot r$, 결합법칙, 예시 $48$ vs $28$. → `cost-compare.svg`
4. **## 마지막 곱셈을 어디서 하는가** — 최상위 괄호 = 마지막 곱, split $k$, 부분 구간 독립성(양옆 행렬이 $M[i,j]$ 에 영향 없음). 점화식·기저. **정리 + 증명**(argviz 조판, 최적 부분구조 = "부분이 최적이 아니면 전체를 개선할 수 있어 모순"). → `split.svg`
5. **## 작은 구간부터 채우기** — 왜 구간 길이순인가($M[i,k],M[k+1,j]$ 는 모두 더 짧은 구간이라 먼저 있어야 함), 삼각 2D 표, C++ 의사코드, $d=[3,2,4,2]$ 채움 예시. → `table-fill.svg`
6. **## 비용 따지기** — 구간 $O(n^2)$ 개 × split $O(n)$ = **$O(n^3)$ 시간, $O(n^2)$ 공간**. 노션의 "$O(n^2)$"는 부분문제 *개수*라서 전체 시간으로 정정.
7. **## 더 나가면** — (원문 밖 확장) 괄호화 복원은 각 칸의 최적 split $k$ 를 저장해 되짚으면 된다는 방향만 짧게. → 추가 설명 `dp-3-traceback`(별도 페이지, 후속) 으로 링크.
8. **## 마치며** — dp-1(주어진 점화식 계산) → dp-2(원소 결정으로 점화식 유도) → dp-3(구간 결정으로 확장) 아크 마무리.

## 코드 (C++ 의사코드)

```cpp
// d[0..n]: Mᵢ 는 d[i-1] x d[i] 행렬.  M₁ x … x Mₙ 의 최소 곱셈 횟수.
int matrixChain(const vector<int>& d, int n) {
    vector<vector<int>> m(n + 1, vector<int>(n + 1, 0));  // m[i][i]=0: 한 행렬은 곱 불필요
    for (int len = 2; len <= n; len++)              // 구간 길이 2..n
        for (int i = 1; i + len - 1 <= n; i++) {    // 구간 [i, j]
            int j = i + len - 1;
            m[i][j] = INT_MAX;
            for (int k = i; k < j; k++)             // 마지막 곱을 (i..k)(k+1..j)로
                m[i][j] = min(m[i][j], m[i][k] + m[k+1][j] + d[i-1]*d[k]*d[j]);
        }
    return m[1][n];
}
```
