- [ ] **Step 1: 유도 섹션 작성**

`## 마지막 날을 포함하는가`를 추가한다.

- $S(n)$ = 앞 $n$일에서 얻을 수 있는 최대 일급으로 정의.
- 최적해가 **마지막 날을 포함하는지**로 이분(노션 A/B 논증을 **자세히** 풀어 씀):
  - **포함(A)**: $a_n$을 얻지만 $n{-}1$일은 **강제로 못 일함** → 남은 최선은 $S(n{-}2)$ → $A=S(n{-}2)+a_n$.
  - **제외(B)**: 마지막 날을 안 하면 $n{-}1$일 제약이 사라져 → $B=S(n{-}1)$.
  - 두 경우가 **겹침 없이 전부**(MECE) → $S(n)=\max\big(S(n{-}1),\,S(n{-}2)+a_n\big)$.
- case-split.svg 삽입:
  `![포함이면 직전 날이 잠기고 S(n-2)+aₙ, 제외면 S(n-1). 둘 중 큰 값이 답이다.](/images/dp-2/case-split.svg)`
- `thm`/`proof` 환경으로 최적 부분구조 간단 논증($S(n{-}1)$, $S(n{-}2)$가 각자 최적이어야 $S(n)$도 최적 — 교환 논법 한 줄).
- 기저 조건 콜아웃(`callout callout-warn` 또는 `callout-key`): $S(0)=0,\ S(1)=a_1$. $n$이 1·2일 때 점화식이 경계를 넘지 않도록.

- [ ] **Step 1: 코드·표 섹션 작성**

`## 상향식으로 채우기`를 추가한다.

- 노션의 **2행 테이블** C++ 의사코드(1-indexed):

```cpp
// a[1..n]: 각 날의 일급.  연속된 두 날은 함께 일할 수 없다.
int selectWorkingDays(const vector<int>& a, int n) {
    vector<array<int,2>> r(n + 1);   // r[i][0]: i일에 안 함, r[i][1]: i일에 함 (각자 최선)
    r[1][0] = 0;
    r[1][1] = a[1];

    for (int i = 2; i <= n; i++) {
        r[i][0] = max(r[i-1][0], r[i-1][1]);   // 안 함 → 전날은 자유
        r[i][1] = r[i-1][0] + a[i];            // 함 → 전날은 반드시 안 함
    }
    return max(r[n][0], r[n][1]);
}
```

- 코드 각 줄이 왜 그런지 설명(저자 노트 "내용을 모르면 왜 저렇게 하는지 알 수 없다" 반영): `r[i][1]`이 `r[i-1][0]`을 참조하는 이유(연속 근무 금지)를 특히 강조.
- 1D $S(\cdot)$ 형과의 대응 한 줄: `S(i)=max(r[i][0],r[i][1])`.
- table-fill.svg 삽입:
  `![일급 [3,5,6,10]을 왼쪽부터 채운다. 함/안 함 두 줄을 이어 계산해 마지막 칸에서 최댓값 15가 나오고, 되짚으면 2·4일을 고른 것이다.](/images/dp-2/table-fill.svg)`
- 복잡도: 칸마다 상수 작업 → **$O(n)$ 시간, $O(n)$ 공간**.
