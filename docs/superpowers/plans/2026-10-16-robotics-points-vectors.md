# 기초 1과 SVG 실험 구현 계획

1. main 기준 격리 worktree를 만들고 인계된 독자·범위·자료를 스펙에 기록한다.
2. 점/원점/변위의 수학 모델과 SVG 4장(조작형 실험의 정적 원본 포함)을 작성한다.
3. 파일명 기반 실험 플러그인, 모듈 로더, 키보드 대체 입력을 구현한다. 기존 단계 재생기의 동작은 유지한다.
4. 승인된 팔레트 매핑·저작 문서·플러그인 및 모델 검사를 확장한다.
5. 기초 1 본문과 robotics 카테고리를 추가한다.
6. Node 테스트·빌드·결정적 검사, 브라우저 조작과 좁은 폭·정적 fallback을 확인한다.
7. 작성자 검증 인계를 남기고 발견한 문제를 수정한다. 기존 리포트의 gate를 실행한다. 새 글의 L1–L7 독립 리뷰와 strict finalize는 리뷰어에게 인계한다.
8. 검증 결과와 리뷰 대기 상태를 담은 draft PR을 만든다. 병합·배포는 별도다.
