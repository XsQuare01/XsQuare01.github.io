# 글쓰기 규칙 — '바른 문장 쓰기'

이 블로그 포스트를 **쓰거나 고칠 때** 지키는 문장 규칙이다. 출처는 이슈 #65와 사용자 지침, 참고 자료 「'바른 문장 쓰기' 원칙」(원칙 1~12)이다.

**적용 시점**: 새 글을 쓸 때는 초안을 마친 뒤 이 체크리스트로 한 번 훑는다. 기존 글을 조판/수정할 때도 같은 PR에서 함께 통과시킨다. `review-post`의 L1 문체 검사도 이 문서를 기준으로 삼는다.

## 대원칙

- **과형식화·과교정 금지.** 의미·수식·코드·용어·직관 설명의 자연스러움은 건드리지 않는다. 문체만 조인다.
- **강박 금지.** 접속어를 0으로 만들거나 '것/의'를 전부 없애려 하지 않는다. 논리 전환에 꼭 필요한 것은 남긴다. 목적은 명료함이지 획일화가 아니다.
- **기술적 정확성 우선.** 아래 문학적 조언은 수학적 정확성, 안정된 용어, 출처와 증명 구조, 수식, 코드, 자연스러운 한국어보다 앞서지 않는다. 짧게 쓰려다 조건이나 논증 단계를 없애지 않는다.
- 코드 주석·인용·수식 내부 텍스트는 대상이 아니다.

## 글을 세우는 규칙

이 절은 작가의 문장을 흉내 내기 위한 인용 모음이 아니다. 검증된 조언을 한국어 기술 글에 맞게 적용한 실무 규칙이다. 따옴표 안 영문만 직접 인용이며, 나머지는 이 블로그를 위한 번역·요약·적용이다.

### 논증과 문단

- [ ] **주장부터 경로를 세운다.** 글의 질문, 답, 답을 지지할 정의·근거·증명 순서를 먼저 적는다. 각 절은 앞 절에서 생긴 질문을 받아 다음 절에 필요한 결론을 내놓는다. *(Zinsser의 논리적 배열 원칙을 기술 글에 적용)*
- [ ] **문단마다 한 가지 일을 맡긴다.** 정의, 예시, 반례, 증명 단계, 해석 가운데 주된 역할을 하나 정한다. 첫 문장과 마지막 문장만 이어 읽어도 논증의 방향이 보이는지 확인한다.
- [ ] **새 독자의 위치를 표시한다.** 용어를 처음 쓰기 전에 정의하고, 기호와 전제를 다시 찾지 않아도 되게 가까운 곳에 둔다. 배경을 모르는 독자가 처음 읽어도 지시어와 생략된 주어의 대상을 찾을 수 있어야 한다. *(Zinsser의 first-time reader 관점을 적용)*
- [ ] **뜻을 먼저 확정한다.** 다듬어진 표현이나 익숙한 문구를 고르기 전에 전달할 정확한 명제를 먼저 적고, 그 뜻에 맞는 말을 고른다. Orwell의 “Let the meaning choose the word, and not the other way about.”을 적용하되 수학적 정밀성과 안정된 용어는 바꾸지 않는다.
- [ ] **추상어를 관찰 가능한 말로 바꾼다.** '효율적이다', '좋다', '크다'로 끝내지 말고 무엇이 얼마나 줄거나 어떤 조건에서 성립하는지 쓴다. 다만 정확한 전문 용어와 이미 정의한 추상 개념은 쉬운 말로 억지로 바꾸지 않는다. *(Orwell의 구체성 원칙을 적용)*

### 초안과 퇴고

- [ ] **초안으로 생각을 발견한다.** 초안에서는 주장과 근거를 끝까지 적는다. 쓰는 동안 드러난 빈틈, 모순, 더 나은 순서는 내용 퇴고에서 고친다. Didion의 “I write entirely to find out what I'm thinking.”을 기술 글의 초안 단계에 적용한 원칙이다.
- [ ] **내용, 구조, 문장을 나누어 고친다.** 먼저 사실·수식·코드를 검증하고, 다음으로 절과 문단의 순서를 고친 뒤, 마지막에 군더더기와 표현을 다듬는다. 문장부터 윤문해 잘못된 구조를 굳히지 않는다.
- [ ] **처음 읽는 사람처럼 다시 읽는다.** 잠시 간격을 두거나 소리 내어 읽으며 정의 누락, 근거 없는 도약, 앞뒤가 바뀐 설명을 찾는다. Zinsser의 “Keep thinking and rewriting until you say what you want to say.”처럼 한 번에 완성하려 하지 않는다.

### 문장과 독자의 시간

- [ ] **문장 구조로 의미 관계를 드러낸다.** 조건은 결론 가까이에, 원인과 결과는 대응하는 자리에 둔다. 같은 사실도 어순과 강조점에 따라 의미가 달라지므로 문장을 단순히 짧게 쪼개지 않는다. *(Didion의 문장 배열에 관한 설명을 기술 글에 적용)*
- [ ] **길이와 리듬을 문맥에 맞춘다.** 짧은 문장으로 핵심을 고정하고, 필요한 곳에서는 긴 문장으로 조건과 관계를 함께 보여 준다. 수동태, 부사, 긴 문장, 전문 용어, 접속어를 일괄 금지하지 않는다.
- [ ] **독자의 시간을 쓴 만큼 돌려준다.** 정의·예시·증명·반례가 주장 이해에 기여하는지 묻고, 기여하지 않는 우회와 반복은 덜어낸다. 단, 증명의 필수 조건이나 재현에 필요한 코드는 줄이지 않는다. Vonnegut의 소설 쓰기 조언에서 독자 시간에 대한 존중만 가져온 적용 규칙이다.

## 체크리스트

### 군더더기 없애기

- [ ] **접속어 최소화 (최우선).** 문두의 '그리고·그런데·그러나·따라서·하지만·그래서·그러니' 남발을 자제한다. 문장 순서·인과로 대체하거나 삭제한다. 접속어는 글의 긴장감을 떨어뜨린다. *(사용자 지침 + 원칙 2)*
- [ ] **보조 용언** 중 불필요한 것 제거. (예: "~해 보다", "~하고 있다"에서 군더더기) *(원칙 1)*
- [ ] **불필요한 수식어**(관형어·부사어) 제거. *(원칙 3)*
- [ ] **접미사 '-들'** 등 문맥상 없어도 되는 복수 표지 생략. *(원칙 4)*
- [ ] **지시어**('이·그·이러한')의 대상이 분명하고 적합한지 점검. *(원칙 5)*

### 중복 없애기

- [ ] **동어 중복** — 같은 단어 반복(의도적 강조가 아니면) 정리. *(원칙 6)*
- [ ] **동의 중복(겹말)** — 같은 뜻이 겹치는 표현 제거. (예: '미리 예상', '역전 앞', '남은 여생') *(원칙 7·8)*
- [ ] **같은 문법 요소 중복** — 조사·어미의 반복으로 흐름이 끊기지 않게 정리. *(원칙 9)*

### 간결·우리말

- [ ] **의존 명사 '것' 줄이기.** '~하는 것이다/~라는 것' 남용을 평서문으로. *(원칙 10)*
- [ ] **불필요한 표현** 제거로 간결화. *(원칙 11)*
- [ ] **관형격 조사 '의' 줄이기.** *(원칙 12)*

## 검출 보조 (참고용, 삭제는 문맥 판단)

편별로 후보를 기계적으로 셀 때 쓰는 표지. 수치는 참고일 뿐, 위반 여부는 문맥으로 판단한다.

```bash
# 문두 접속어
grep -oE '(^|[.」”"] ?)(하지만|그리고|그런데|따라서|그러나|그래서|그러니|그러면)' <파일> | wc -l
# 의존명사 '것'
grep -oE '것(이다|이|을|은|과|도|만|의|들)?' <파일> | wc -l
# 복수 '-들'
grep -oE '[가-힣]들' <파일> | wc -l
```

## 완료 기준 (편당)

- 글의 질문, 답, 근거와 증명 순서가 이어지고 각 문단의 역할이 분명하다.
- 처음 읽는 독자가 용어·기호·지시 대상을 찾을 수 있고, 추상적인 평가는 조건이나 관찰 가능한 결과로 뒷받침된다.
- 사실과 구조를 먼저 검토한 뒤 문장을 퇴고했으며, 문장 길이와 리듬이 의미 관계를 가리지 않는다.
- 문두 접속어가 꼭 필요한 곳에만 남는다.
- 겹말·군더더기·불필요한 '것/의/-들'이 줄어 문장이 짧고 또렷하다.
- 의미·수식·코드는 그대로다. 직관 설명의 자연스러움을 해치지 않는다.
- `npm run build` 통과.

## 인용과 귀속 주의

- **Hemingway 오인용**: “Write drunk, edit sober.”와 “There is nothing to writing. All you do is sit down at a typewriter and bleed.”는 검증 가능한 1차 출처 없이 Hemingway의 말로 인용하지 않는다. 이 문서의 규칙을 Hemingway의 말로 바꾸어 소개하지 않는다.
- **“Kill your darlings”**: 여러 작가에게 귀속되는 통용 문구다. 특정 작가의 직접 인용으로 쓰지 말고, 필요하면 출처와 정확한 원문을 별도로 확인한다.
- **Strunk와 White 구분**: “Omit needless words.”는 E. B. White가 참여하기 전 William Strunk Jr.의 단독 저술 판본에 나온다. 후대의 *The Elements of Style* 전체를 말할 때만 Strunk와 E. B. White를 함께 적는다.
- **부사 절대 금지 금지**: 작가의 장르별 선호나 조건부 조언을 모든 글의 법칙으로 만들지 않는다. 부사, 수동태, 긴 문장은 뜻과 논증을 흐릴 때 고치며 기계적으로 삭제하지 않는다.

- Kurt Vonnegut, “Creative Writing 101,” *Bagombo Snuff Box* (1999). 독자의 시간을 존중하라는 소설 쓰기 조언에서 기술 글에도 맞는 부분만 적용했으며, 소설의 다른 규칙을 보편 법칙으로 삼지 않는다.
