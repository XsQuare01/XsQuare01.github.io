# SVG 조작형 실험

본문에는 Markdown 이미지 한 줄을 쓴다. 파일명은 `-lab.svg`로 끝내고, 루트 `<svg>`에 등록된 `data-lab` 값을 둔다. 예: `![설명](/images/robotics-points-vectors/displacement-lab.svg)`.

`src/plugins/rehype-svg-labs.mjs`가 `rehypeFigureCaption` 뒤에서 해당 이미지를 찾는다. 원본 img와 숨긴 인라인 복사본을 함께 두며 캡션은 보존한다. `src/labs/index.js`의 닫힌 목록에 등록된 실험 모듈이 복사본을 초기화하고 성공한 뒤에만 표시한다. 동작 코드는 본문이나 SVG 파일 안에 넣지 않는다.

## 파일 계약

- 파일은 저장소가 관리하는 `public/images/` 내부에 있다. SVG 업로드 처리나 임의 SVG 정제 기능이 아니다.
- `<svg>`로 시작하고 `</svg>`로 끝낸다. 속성은 겹따옴표로 쓴다. `script`, `style`, `foreignObject`, 이벤트 속성은 사용하지 않는다.
- 실험 종류는 플러그인(`LABS`)과 런타임 등록부(`LAB_MODULES`)에 모두 등록한다. 한쪽에만 있으면 오류 없이 원본 이미지로 남으므로, `test/lab-loader.test.mjs`가 두 목록이 같은지와 각 모듈이 `mount`를 내보내는지 검사한다.
- id와 `url(#id)` 참조에는 파일 경로와 사용 횟수에 따른 접두어가 붙는다. 모듈은 id 대신 `data-part`로 요소를 찾는다.
- 실험의 수학 모델은 DOM과 분리해 Node 테스트로 검증한다. 각 모듈은 초기화 성공 전까지 `.is-live`를 붙이지 않는다.
- SVG 파일 자체가 본문 예제의 읽을 수 있는 초기 그림이어야 한다. JavaScript 없이도 원본 이미지와 캡션으로 내용이 전달된다.
- 정적 SVG는 실험의 첫 화면과 같아야 한다. 점·라벨 위치를 모델의 계산 함수에서 얻고, 정적 파일의 값이 그 계산과 같은지 Node 테스트로 대조한다. 따로 손으로 맞추면 JS 없는 그림과 실험 첫 화면이 어긋난다.
- 끌 수 있는 요소에 CSS `touch-action`만 걸면 안 된다. 브라우저는 SVG 안쪽 요소가 아니라 바깥 `<svg>`에서 터치 동작을 판정하므로, 터치 화면에서 페이지가 대신 움직이고 드래그가 끊긴다. 손잡이에서 시작한 `touchstart`만 기본 동작을 막는다(`passive: false`).
- 상태에 따라 움직이는 라벨은 고정 오프셋으로 놓지 않는다. 눈금 숫자·축 글자·점·선분과 먼저 놓은 라벨을 장애물로 두고 빈 후보 자리를 고르며, 놓을 수 없으면 숨기고 같은 값을 읽기 값으로 보인다. 표본 몇 개가 아니라 입력이 만들 수 있는 상태 전체를 훑는 테스트로, 모델과 독립된 상자 계산을 써서 겹침이 없음을 검사한다. 0에 가까워지는 선분처럼 붙일 자리가 사라지는 대상에는 움직이는 라벨 대신 고정 범례를 쓴다.
- 손잡이가 겹칠 수 있으면(영벡터가 두 손잡이를 한 자리에 놓는 경우 등) 맨 위에 그린 손잡이가 포인터를 독차지한다. `src/labs/pick-handle.mjs`로 포인터에서 가장 가까운 손잡이를 고르고, 거리가 같으면 선택 상자에서 고른 쪽을 남긴다.
- 화살촉 참조는 `marker-end`와 함께 `data-marker`에도 적는다. 런타임은 짧은 화살표에서 `marker-end`를 떼었다 다시 붙이는데, 첫 화면의 `marker-end`에서 참조를 읽으면 첫 화면에 짧은 화살표가 있을 때 참조를 잃는다. 플러그인은 `url(#id)`를 속성과 관계없이 접두어로 바꾸므로 `data-marker`도 함께 바뀐다.
- 그림 일부가 통째로 도는 실험은 도는 요소를 자기 좌표로 그린 묶음 하나에 넣고 `rotate(각 cx cy)`만 바꾼다. 테스트는 모델의 회전 식을 다시 쓰지 않고, SVG `rotate`의 정의를 직접 적용해 그린 위치를 독립 검산한다. 잘라 그릴 격자는 같은 `rotate`를 건 묶음을 하나 더 두고 그 바깥에 `clip-path`를 건다. `clip-path`를 회전 묶음에 직접 걸면 잘라 내는 사각형도 함께 돈다. 도는 요소가 그림 안의 고정 글자(눈금 숫자, O)를 지나가므로 그런 글자는 그림 사각형 밖이나 범례로 옮긴다.
- 인쇄할 때는 조작 중인 DOM 대신 원본 이미지를 표시한다. 초기 상태임을 본문과 캡션에 명시한다.
- 팔레트 정본은 `DIAGRAM_PALETTE.md`다. `svg-labs.css`가 인라인 SVG에 같은 토큰을 매핑한다. 정적 fallback에도 색 속성은 남는다.
- 포인터 조작에는 native 입력 등 동등한 키보드 경로를 둔다. 자동 재생을 기본으로 만들지 않는다.

## 검증

`npm run test:js`는 기존 단계 도식, 실험 플러그인, 점/벡터 모델과 팔레트, 로더의 fallback(미등록·불러오기 실패·초기화 도중 실패)을 검사한다. Markdown 이미지 구문을 유지하므로 포스트 검사의 D4·D5·D13도 원본 SVG를 찾는다. 모듈의 실제 포인터/키보드 동작, 텍스트 겹침, 작은 화면, JS 차단, 인쇄 상태는 브라우저에서 별도로 확인한다.

HTML 표·격자 단계 도식(#238)은 별도 범위다. 이 규약은 좌표를 직접 그리는 SVG 실험만 다룬다.
