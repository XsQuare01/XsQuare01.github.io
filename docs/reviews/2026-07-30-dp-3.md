### 🟢 [L6] 노션 원문 대조 완료 — 정리 1 증명은 승인된 확장으로 분류

- severity: 🟢
- source: L
- rule_id: L6
- location: src/content/posts/dp-3.md:64-91,124-126,130-134 / Notion "Dynamic programming 3"(378cb27e-4930-80df-bce6-fbd4c5df2da5) / .superpowers/sdd/2026-07-30-dp-3/progress.md:3 / docs/superpowers/plans/2026-07-30-dp-3.md:13
- quote: "행렬곱은 결합법칙이 성립하므로, 어떤 순서로 계산하는지 동일하다... 앞/뒤의 계산에 영향을 받지 않기에 위의 앞/뒤 행렬곱은 서로에게 영향을 미치지 않는다... 어느 '마지막 곱하기'가 가장 좋은 결과를 내는지 '알 수 없다'. 따라서, 모든 곱하기에 대해 '마지막 곱하기'라고 가정하고 다 해보는 수밖에 없다."(Notion 원문)
- message: 이번 리뷰는 `notion-search`/`notion-fetch`로 노션 "Dynamic programming 3" 페이지(부모: "알고리즘 수업 정리")를 실제로 가져와 대조했다. 이 페이지는 "Path counting"(격자 경로 개수 세기)과 "Matrix multiplication"(행렬 곱셈 순서) 두 독립된 주제를 담고 있는데, dp-3 포스트는 Matrix multiplication 부분만 다룬다. Path counting은 본문에 전혀 언급되지 않지만, 이는 계획 문서(`docs/superpowers/plans/2026-07-30-dp-3.md` Goal/Global Constraints)가 "행렬 곱셈 순서(matrix chain) 구간 DP"만 다루도록 처음부터 명시적으로 범위를 좁힌 결과이지, 다루기로 한 내용을 빠뜨린 누락이 아니다. Matrix multiplication 부분 안에서는 문제 정의($M_i=d_{i-1}\times d_i$), 결합법칙으로 결과는 같지만 순서에 따라 비용이 다르다는 도입, "마지막 곱하기"를 기준으로 사슬을 가르는 결정, 부분 구간이 앞뒤 계산에 영향받지 않는다는 독립성 논거, 점화식 $\min_k(D_{i,k}+D_{k+1,j}+d_{i-1}d_kd_j)$, 짧은 구간부터 채우는 순서, $D[1,n]$이 정답이라는 결론까지 원문 줄기가 그대로 보존된다. 노션 코드는 대각 초기화 루프로 $D[i][i]=0$을 설정하는데, 산문 설명 한 줄("i=j-1인 경우는 0")은 표기가 어긋나 있어 코드가 더 신뢰할 수 있는 근거이고, 포스트의 $M[i,i]=0$ 기저는 코드가 실제로 구현하는 의미와 일치한다(원문의 산문 오기를 코드 기준으로 바로잡은 것으로 hallucination이 아니다). 세 가지는 노션에 없는 확장이며 각각의 승인 근거가 있다: ① 정리 1의 형식적 증명(상계·하계 양방향)은 노션의 비정형 논거("독립적이다 → 모든 마지막 곱을 시도해본다")를 엄밀하게 조판한 것으로, `.superpowers/sdd/2026-07-30-dp-3/progress.md`의 Task 1 판정("adjudicated Important (proof provenance) — ruling: 승인된 추가 per spec §확장 '정리·증명의 엄밀 조판'; Notion DP3 carries informal argument spine; mirrors dp-2 precedent")에 따라 **승인된 확장(approved extension)**으로 분류한다. ② $O(n^3)$ 시간·$O(n^2)$ 공간 복잡도 분석("비용 따지기" 절)은 노션 원문에 명시적 복잡도 진술이 없어 추가된 내용이지만 `docs/superpowers/plans/2026-07-30-dp-3.md`의 Global Constraints가 "O(n³) 정정"을 승인된 확장으로 이미 명시했고 독립 검산으로도 정확하다. ③ $(3\times2)(2\times4)(4\times2)$, $d=[3,2,4,2]$ 구체 수치 예제(48/28/24/16)는 노션이 추상적 $M_i=d_{i-1}\times d_i$ 표기에 머무는 것과 달리 새로 추가된 구체화 예시이지만, 수식·결론을 바꾸지 않고 원문의 일반 공식을 정확히 예시로 구현할 뿐이라 dp-2의 구체 임금 예제([3,5,6,10]) 선례와 같은 성격의 교육적 확장이다. "더 나가면" 절의 복원 예고도 본문에서 "강의 노트에 없는 확장"이라 스스로 밝힌다. 요약하면 다루는 범위 안에서 hallucination이나 핵심 누락은 없고, 확장분은 모두 출처가 분명하며 그중 정리 1 증명은 승인된 확장으로 공식 기록한다.
- recommendation: 수정 없음. 향후 Path counting을 별도 포스트로 다룰지는 시리즈 기획 단계에서 결정할 사항으로 남긴다.
- gate_effect: info

### 🟢 [L7] 점화식·복잡도·증명 정확성 점검 완료

- severity: 🟢
- source: L
- rule_id: L7
- location: src/content/posts/dp-3.md:31-35,47-91,101-118,124-126
- quote: "M[i,j] = min_{i≤k<j}(M[i,k] + M[k+1,j] + d_{i-1} d_k d_j)"
- message: 검토 완료, 이슈 없음. 독립 재계산 결과 도입 예시(왼쪽 3·2·4+3·4·2=48, 오른쪽 2·4·2+3·2·2=28), $d=[3,2,4,2]$의 $M[1,2]=24$, $M[2,3]=16$, $M[1,3]=\min(0+16+12,\,24+0+24)=\min(28,48)=28$이 모두 점화식과 서로 정확히 맞는다(오른쪽 묶기 28이 $k=1$ 분기, 왼쪽 묶기 48이 $k=2$ 분기와 정확히 대응). 정리 1의 증명은 하계(고정한 최적 괄호화의 좌우 부분이 각각 정확히 $M[i,k^*]$, $M[k^*+1,j]$여야 함을 모순으로 보임)와 상계(각 $k$에 대해 실제 구성 가능한 괄호화 제시)를 모두 갖춰 MECE하게 닫힌다 — $k$의 범위 $i\le k<j$가 사슬의 가능한 모든 마지막 분할점을 빠짐없이·겹침 없이 포괄한다. `matrixChain` 코드는 점화식을 정확히 구현하고(`m[i][k]+m[k+1][j]+d[i-1]*d[k]*d[j]`), 대각 $m[i][i]=0$은 `vector` 기본값 0으로 처리된다는 설명과 실제 초기화가 일치한다. 복잡도 $O(n^2)$ 칸 $\times$ 칸당 $O(n)$ = $O(n^3)$ 시간, $O(n^2)$ 공간 계산도 표준 구간 DP 분석과 일치하고, "칸의 개수는 부분 문제 개수일 뿐 전체 시간이 아니다"라는 구분도 정확하다.
- recommendation: 수정 없음.
- gate_effect: info
